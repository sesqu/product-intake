# Moduły odłożone

Te integracje są zachowane, ale **nie należą do aktywnej ścieżki aplikacji**.

- `amazon.js` — Amazon SP-API. Odłożony do czasu uzyskania prawidłowego dostępu.
- `keepa.js` — Keepa. Odłożona, ponieważ API wymaga płatnego klucza.

Kod pozostaje w repo jako materiał do późniejszego ponownego włączenia. Aktywna aplikacja nie importuje tych plików, nie pokazuje ich jako źródeł wyszukiwania i nie odpytuje ich endpointów.
